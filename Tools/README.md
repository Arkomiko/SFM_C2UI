# Tools

Utilities built on Core. They are not part of the shipped editor.

| Tool | Purpose |
|---|---|
| `Localization/` | Authoring translations |
| `Market Load/` | The marketplace client for plugins and addons (planned) |
| `NewPlugins/` | Authoring plugins |
| `UI/` | Authoring themes and workspaces |

Each one is written strictly against `Core/API` - they are how we find out
whether that API is good enough for anyone else to build on.
