本ライセンスは Arkomiko によるプロジェクト C2UI (Custom to User Interface) 自身のコードに適用されます。Valve のファイルはプロジェクトに含まれません。

## C2UI のコード

1. **利用。** コードは個人的・非商用の目的で自由に利用できます。
2. **商用。** あらゆる商用利用は作者と合意し、作者の書面による同意を必要とします。
3. **改変。** 改変版を変更・配布する際は、元プロジェクト (https://github.com/Arkomiko/SFM_C2UI) へのリンクと作者 Arkomiko を明記してください。
4. **第三者の権利。** Source Filmmaker、Team Fortress 2、Source エンジンは Valve に帰属します。本プロジェクトはそれらの形式を読み、ファイルを含まず、Steam 経由でインストールされた SFM とのみ動作します。

## プラグインとアドオン — C2UI — Plugins & Addons (C2UI‑Pl&AD)

- プラグインとアドオンは Source エンジンと C2UI の追加リソースです。
- 第三者のライブラリ (Valve、Garry's Mod、Steinberg など) を基にしたプラグインやアドオンは、それらのライブラリのライセンスで配布されます。
- それ以外は C2UI‑Pl&AD ライセンスが適用されます。これは未実装の将来の C2UI マーケットプレイスの枠内に存在します: 無料のプラグイン・アドオンの作者はすべての権利を保持し、有料のプラグイン・アドオンは 500 ダウンロードを超えた後、各販売の 20 % を納めます。
- マーケットプレイス開始まで、すべては C2UI とプラグイン・アドオン自身の作者を明記した上で自由かつ改変可能のままです。
