Lisensi iki nglingkupi kode dhewe proyek C2UI (Custom to User Interface) dening Arkomiko. File Valve dudu bagéan saka proyek.

## Kode C2UI

1. **Panggunaan.** Kode bisa digunakake kanthi bebas kanggo tujuan pribadi lan non-komersial.
2. **Komersial.** Saben panggunaan komersial kudu disepakati karo penulis lan mbutuhake persetujuan tinulisé.
3. **Owah-owahan.** Versi sing diowahi, nalika diowahi lan disebarake, kudu nyambung menyang proyek asli (https://github.com/Arkomiko/SFM_C2UI) lan nyebutake penulisé, Arkomiko.
4. **Hak pihak katelu.** Source Filmmaker, Team Fortress 2 lan mesin Source iku duweké Valve. Proyek maca formaté, ora ngemot filené, lan mung bisa karo salinan SFM sing dipasang liwat Steam.

## Plugin lan addon — C2UI — Plugins & Addons (C2UI‑Pl&AD)

- Plugin lan addon iku sumber daya tambahan mesin Source lan C2UI.
- Plugin utawa addon sing dibangun ing pustaka pihak katelu (Valve, Garry's Mod, Steinberg lan liya-liyané) disebarake miturut lisensi pustaka kuwi.
- Yen ora, lisensi C2UI‑Pl&AD sing ditrapake. Lisensi iki ana ing kerangka pasar C2UI ing mangsa ngarep sing durung digawé: penulis plugin utawa addon gratis tetep nduweni kabeh hak; plugin utawa addon mbayar nyetor 20% saka saben dodolan sawisé 500 undhuhan.
- Nganti pasar diluncurake, kabeh tetep bebas lan bisa diowahi, kanthi nyebutake C2UI lan penulis plugin utawa addon dhewe.
