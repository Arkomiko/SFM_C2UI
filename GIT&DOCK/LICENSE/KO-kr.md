이 라이선스는 Arkomiko의 C2UI(Custom to User Interface) 프로젝트 자체 코드에 적용됩니다. Valve의 파일은 프로젝트에 포함되지 않습니다.

## C2UI 코드

1. **이용.** 코드는 개인적·비상업적 목적으로 자유롭게 이용할 수 있습니다.
2. **상업.** 모든 상업적 이용은 저자와 합의해야 하며 저자의 서면 동의가 필요합니다.
3. **수정.** 수정본을 변경·배포할 때는 원본 프로젝트(https://github.com/Arkomiko/SFM_C2UI) 링크와 저자 Arkomiko를 명시해야 합니다.
4. **제3자 권리.** Source Filmmaker, Team Fortress 2, Source 엔진은 Valve에 귀속됩니다. 프로젝트는 그 형식을 읽고, 파일을 포함하지 않으며, Steam으로 설치된 SFM 사본과만 작동합니다.

## 플러그인과 애드온 — C2UI — Plugins & Addons (C2UI‑Pl&AD)

- 플러그인과 애드온은 Source 엔진과 C2UI의 추가 리소스입니다.
- 제3자 라이브러리(Valve, Garry's Mod, Steinberg 등)를 기반으로 만든 플러그인이나 애드온은 해당 라이브러리의 라이선스로 배포됩니다.
- 그 외에는 C2UI‑Pl&AD 라이선스가 적용됩니다. 아직 구현되지 않은 미래의 C2UI 마켓플레이스 틀 안에 존재합니다: 무료 플러그인·애드온의 저자는 모든 권리를 보유하고, 유료 플러그인·애드온은 500회 다운로드 이후 매 판매의 20%를 납부합니다.
- 마켓플레이스가 열릴 때까지 모든 것은 C2UI와 플러그인·애드온 저자를 명시하는 조건으로 자유롭고 수정 가능하게 유지됩니다.
