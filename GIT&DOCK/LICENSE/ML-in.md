ഈ ലൈസൻസ് Arkomiko-യുടെ C2UI (Custom to User Interface) പ്രോജക്റ്റിന്റെ സ്വന്തം കോഡിന് ബാധകമാണ്. Valve-ന്റെ ഫയലുകൾ പ്രോജക്റ്റിന്റെ ഭാഗമല്ല.

## C2UI കോഡ്

1. **ഉപയോഗം.** കോഡ് വ്യക്തിഗതവും വാണിജ്യേതരവുമായ ആവശ്യങ്ങൾക്ക് സ്വതന്ത്രമായി ഉപയോഗിക്കാം.
2. **വാണിജ്യം.** ഏതൊരു വാണിജ്യ ഉപയോഗവും രചയിതാവുമായി ധാരണയിലെത്തണം, രേഖാമൂലമുള്ള സമ്മതം ആവശ്യമാണ്.
3. **പരിഷ്കരണം.** പരിഷ്കരിച്ച പതിപ്പുകൾ മാറ്റുമ്പോഴും വിതരണം ചെയ്യുമ്പോഴും യഥാർത്ഥ പ്രോജക്റ്റിന്റെ (https://github.com/Arkomiko/SFM_C2UI) ലിങ്കും രചയിതാവ് Arkomiko-യുടെ പേരും നൽകണം.
4. **മൂന്നാം കക്ഷി അവകാശങ്ങൾ.** Source Filmmaker, Team Fortress 2, Source എഞ്ചിൻ Valve-ന്റേതാണ്. പ്രോജക്റ്റ് അവയുടെ ഫോർമാറ്റുകൾ വായിക്കുന്നു, ഫയലുകൾ ഉൾക്കൊള്ളുന്നില്ല, Steam വഴി ഇൻസ്റ്റാൾ ചെയ്ത SFM പകർപ്പുമായി മാത്രം പ്രവർത്തിക്കുന്നു.

## പ്ലഗിനുകളും ആഡ്ഓണുകളും — C2UI — Plugins & Addons (C2UI‑Pl&AD)

- പ്ലഗിനുകളും ആഡ്ഓണുകളും Source എഞ്ചിന്റെയും C2UI-യുടെയും അധിക വിഭവങ്ങളാണ്.
- മൂന്നാം കക്ഷി ലൈബ്രറികളെ (Valve, Garry's Mod, Steinberg മുതലായവ) അടിസ്ഥാനമാക്കിയ പ്ലഗിൻ അല്ലെങ്കിൽ ആഡ്ഓൺ ആ ലൈബ്രറികളുടെ ലൈസൻസുകൾ പ്രകാരം വിതരണം ചെയ്യുന്നു.
- അല്ലാത്തപക്ഷം C2UI‑Pl&AD ലൈസൻസ് ബാധകമാണ്. ഇത് ഇതുവരെ നടപ്പാക്കാത്ത ഭാവി C2UI മാർക്കറ്റ്‌പ്ലേസിന്റെ ചട്ടക്കൂടിലാണ്: സൗജന്യ പ്ലഗിൻ അല്ലെങ്കിൽ ആഡ്ഓണിന്റെ രചയിതാവ് എല്ലാ അവകാശങ്ങളും നിലനിർത്തുന്നു; പണമടച്ചുള്ള പ്ലഗിൻ അല്ലെങ്കിൽ ആഡ്ഓൺ 500 ഡൗൺലോഡുകൾക്ക് ശേഷം ഓരോ വിൽപ്പനയുടെയും 20% നൽകുന്നു.
- മാർക്കറ്റ്‌പ്ലേസ് ആരംഭിക്കുന്നതുവരെ എല്ലാം C2UI-യെയും പ്ലഗിൻ അല്ലെങ്കിൽ ആഡ്ഓണിന്റെ രചയിതാക്കളെയും പരാമർശിച്ചുകൊണ്ട് സ്വതന്ത്രവും പരിഷ്കരിക്കാവുന്നതുമായി തുടരുന്നു.
