## ആശയം

Source Filmmaker ശക്തമായ ഒരു ഉപകരണമാണ്, പക്ഷേ അതിന്റെ ഇന്റർഫേസ് 2012-ൽ തന്നെ നിൽക്കുന്നു. C2UI അതിനെ മാറ്റിസ്ഥാപിക്കുകയോ പുനർനിർമ്മിക്കുകയോ ചെയ്യുന്നില്ല: ലക്ഷ്യം SFM-നെ അൽപ്പം കൂടി ആധുനികവും സൗകര്യപ്രദവുമാക്കുക മാത്രം.

എഡിറ്റർ ഇൻസ്റ്റാൾ ചെയ്ത SFM കണ്ടെത്തി, അതിനെ ഉള്ളടക്ക ലൈബ്രറിയായി ബന്ധിപ്പിക്കുന്നു — മോഡലുകൾ, മെറ്റീരിയലുകൾ, ടെക്സ്ചറുകൾ, സെഷനുകൾ — അതേ ഫയലുകളുമായി അതേ ഫോർമാറ്റിൽ പ്രവർത്തിക്കുന്നു. SFM-ൽ ഉണ്ടാക്കിയതെല്ലാം C2UI-ൽ തുറക്കും, തിരിച്ചും.

ആദ്യ ലക്ഷ്യം എല്ലുകളും റിഗുകളും ഉൾപ്പെടെ SFM-മായി പൂർണ്ണ അനുയോജ്യത. പിന്നെ — SFM-ൽ ഇല്ലാതിരുന്നവ.

```
  ┌──────────────┐                        ┌──────────────────────────────┐
  │   C2UI       │ ──── "SFM എവിടെ?" ────▶│  SourceFilmmaker/game/       │
  │              │                        │    usermod/gameinfo.txt      │
  │  സ്വന്തം UI    │ ◀──────── മൗണ്ട് ────────│    tf/  hl2/  tf_movies/ …   │
  │  സ്വന്തം റെൻഡർ │       വായന മാത്രം       │    models/ materials/ dmx    │
  └──────────────┘                        └──────────────────────────────┘
```

- **പോർട്ടബിൾ.** ആപ്ലിക്കേഷൻ ഫോൾഡറിന് പുറത്ത് ഒന്നും എഴുതുന്നില്ല: സെറ്റിംഗുകൾ `App/User`, കാഷ് `App/Cache`, താൽക്കാലികം `App/Temporary`. ഫോൾഡർ ഇല്ലാതാക്കൂ, ഒരു അടയാളവുമില്ല.
- **SFM ഒരിക്കലും പ്രവർത്തിപ്പിക്കുന്നില്ല.** നിയന്ത്രിക്കാൻ പ്രോസസ്സില്ല, പിടിച്ചെടുക്കാൻ വിൻഡോകളില്ല. ഇൻസ്റ്റാളേഷൻ ഒരു ഉള്ളടക്ക പാക്ക് പോലെ വായിക്കുന്നു.
- **ഫോർമാറ്റുകൾ പരിശോധിച്ചത്, ഊഹിച്ചതല്ല.** ഓരോ റീഡറും യഥാർത്ഥ ഇൻസ്റ്റാളേഷനുമായി ഒത്തുനോക്കി; ഫോർമാറ്റ് അപ്രതീക്ഷിതമായത് ചെയ്യുന്നിടത്ത് കോഡ് പറയുന്നു.
- **സേവ് കൃത്യമാണ്.** മാറ്റമില്ലാതെ വായിച്ച് എഴുതിയ സെഷൻ അതേ ഫയലാണ്.
- **എഞ്ചിന് ആശ്രിതത്വങ്ങളില്ല.** `Core/` ഉം മുഴുവൻ ടെസ്റ്റ് സ്യൂട്ടും ശുദ്ധ Python-ൽ ഓടുന്നു; വിൻഡോയ്ക്ക് മാത്രം Qt ഉം OpenGL ഉം വേണം.

### ഇത് എങ്ങനെ പ്രവർത്തിക്കുന്നു

«Source Filmmaker എവിടെ?» എന്നതിൽ നിന്ന് സ്ക്രീനിലെ ഒരു ഫ്രെയിം വരെയുള്ള പാത അഞ്ച് പാളികളിലൂടെ കടന്നുപോകുന്നു; ഓരോ പാളിക്കും അതിനു തൊട്ടുതാഴെയുള്ളത് മാത്രമേ അറിയൂ.

1. **ബ്രിഡ്ജ്** (`Core/dev-kit/bridge_sfm`) Steam വഴി ഇൻസ്റ്റാളേഷൻ കണ്ടെത്തുന്നു, `gameinfo.txt` വായിക്കുന്നു, എഞ്ചിന്റെ ക്രമത്തിൽ ഉള്ളടക്ക പാതകൾ തിരികെ നൽകുന്നു. `sfm.exe` ഒരിക്കലും തുറക്കപ്പെടുന്നില്ല.
2. **വെർച്വൽ ഫയൽ സിസ്റ്റവും സൂചികയും** (`Core/Code/vfs.py`, `content_index.py`) ആ പാതകളെ Source പോലെ അടുക്കുന്നു: ആദ്യം കണ്ടെത്തുന്ന ഫയൽ ജയിക്കുന്നു. സൂചിക `App/Cache`-ലെ ഒരൊറ്റ SQLite ഫയലാണ്, അതിനാൽ 70 000 ഫയലുകളിലൂടെയുള്ള നടത്തം ഒരിക്കൽ മാത്രം.
3. **ഫോർമാറ്റുകൾ** (`Core/Code/formats`) മൂന്നാം കക്ഷി ലൈബ്രറികളില്ലാതെ Valve-ന്റെ ഫയലുകൾ വായിക്കുന്നു: `.mdl` `.vvd` `.vtx` ഒരു മോഡൽ, `.vmt` `.vtf` മെറ്റീരിയലും ടെക്സ്ചറും, `.dmx` ഒരു സെഷൻ, `.bsp` ഒരു മാപ്പ്. ഓരോ റീഡറും മുഴുവൻ ഇൻസ്റ്റാളേഷനിലും പരിശോധിച്ചതാണ്; സെഷൻ ബൈറ്റ്-ബൈ-ബൈറ്റ് അതേപടി തിരികെ എഴുതപ്പെടുന്നു.
4. **സെഷൻ** DMX ഘടകങ്ങളുടെ ഒരു ഗ്രാഫാണ്. `animation.py` ഒരു നിമിഷത്തിലെ ചാനലുകൾ കണക്കാക്കുന്നു, `operators.py` എക്സ്പ്രഷനുകളും റിഗ് കൺസ്ട്രെയിന്റുകളും നടപ്പിലാക്കുന്നു, `flex.py` മുഖങ്ങൾ ചലിപ്പിക്കുന്നു, `pose.py` അസ്ഥി മാട്രിക്സുകൾ നിർമ്മിക്കുന്നു. ഓരോ എഡിറ്റും `editing.py` വഴി പഴയപടിയാക്കാവുന്ന കമാൻഡായി കടന്നുപോകുന്നു.
5. **എഡിറ്റർ** (`App/Code`) ഇതിൽ നിന്ന് ഒരു രംഗം (`render/scene.py`) ഒരുക്കി സ്വന്തം OpenGL 3.3 റെൻഡറർ (`renderer.py`, `shaders.py`) കൊണ്ട് വരയ്ക്കുന്നു: സെഷൻ ലൈറ്റുകൾ, ലൈറ്റ്മാപ്പുകൾ, മാപ്പിന്റെ വെളിച്ചം — SFM കാണിക്കുന്നതുപോലെ. പാനലുകൾ (`ui/`): ടൈംലൈൻ, സെഷൻ ട്രീ, ഇൻസ്പെക്ടർ, ഗ്രാഫ് എഡിറ്റർ, UE5 ശൈലിയിലുള്ള ഡോക്കിംഗ്.

പ്രോഗ്രാം എഴുതുന്നതെല്ലാം അതിന്റെ ഫോൾഡറിനുള്ളിൽ തന്നെ: ക്രമീകരണങ്ങൾ `App/User`-ൽ, സൂചികയും കാഷും `App/Cache`-ൽ, ലോഗ് `App/Temporary`-ൽ. `Core/` ഒന്നും എഴുതുന്നില്ല, Qt-യെ ആശ്രയിക്കുന്നുമില്ല; അതിനാൽ എഞ്ചിനും ടെസ്റ്റുകളും ശുദ്ധ Python-ൽ പ്രവർത്തിക്കുന്നു; Qt-യും OpenGL-ഉം വിൻഡോയ്ക്ക് മാത്രം ആവശ്യം. `Tools/`-ലെ ഉപകരണങ്ങൾ കർശനമായി `Core/API`-യിൽ നിർമ്മിച്ചവയാണ് — ആ API മൂന്നാം കക്ഷി പ്ലഗിനുകൾക്കും മതിയാകുമെന്ന് ഇങ്ങനെ തെളിയിക്കപ്പെടുന്നു.

### പ്രവർത്തിപ്പിക്കൽ

Windows, Python 3.13, Source Filmmaker ഇൻസ്റ്റാളേഷൻ ആവശ്യമാണ്.

```bash
git clone https://github.com/Arkomiko/SFM_C2UI.git
cd SFM_C2UI
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r Tools/Launcher/requirements.txt
.venv/Scripts/python.exe Tools/Launcher/c2ui.py
```

ആദ്യ തുടക്കത്തിൽ Steam വഴി SFM തിരയുന്നു; കിട്ടിയില്ലെങ്കിൽ ചോദിക്കുന്നു. <kbd>Ctrl</kbd>+<kbd>O</kbd> സെഷൻ തുറക്കുന്നു, <kbd>Space</kbd> പ്ലേ, <kbd>C</kbd> ഷോട്ട് കാമറ, <kbd>T</kbd>/<kbd>R</kbd> മൂവ്/റൊട്ടേറ്റ്, <kbd>M</kbd> മോഷൻ എഡിറ്റർ, <kbd>Ctrl</kbd>+<kbd>Z</kbd> അൻഡു, <kbd>Ctrl</kbd>+<kbd>S</kbd> സേവ്. പാനലുകൾ തലക്കെട്ടിൽ പിടിച്ച് വലിക്കുന്നു. ടെസ്റ്റുകൾക്ക് ഒന്നും വേണ്ട:

```bash
python Testing/run.py
```

### പദ്ധതിയിൽ

**അടുത്തത്**
- മാപ്പിന്റെ രൂപം: വെള്ളം, prop_dynamic, ലൈറ്റുകളുടെ ഗോബോ ടെക്സ്ചറുകൾ, `$bumpmap`-ഉം `$envmap`-ഉം, സെഷൻ ലൈറ്റുകളിൽ നിന്നുള്ള നിഴലുകൾ.
- എക്സ്പോർട്ട് ചെയ്ത സിനിമകളിൽ ശബ്ദം.
- `.c2plg` പ്ലഗിനുകളും `Tools/Market Load`-ലെ മാർക്കറ്റ്പ്ലേസ് ക്ലയന്റും; തുടർന്ന് തീമുകളും വർക്ക്സ്പേസുകളും.
- ടൈംലൈനിൽ ശബ്ദം, പാർട്ടിക്കിളുകൾ, റിങ്കിൾ മാപ്പുകൾ, മോഷൻ എഡിറ്റർ പ്രീസെറ്റുകളും ലെയറുകളും, ഗ്രാഫ് എഡിറ്ററിലെ ടാൻജന്റുകൾ.

**പിന്നീട്**
- പൂർണ്ണ മാപ്പുകളിലെ പ്രകടനം: സ്റ്റാറ്റിക് പ്രോപ്പ് ഇൻസ്റ്റൻസിംഗ്, പോസ് കാഷ്.
- എഞ്ചിൻ പുനർനിർമ്മാണം: മെച്ചപ്പെട്ട വെളിച്ചത്തിനും നിഴലുകൾക്കുമായി പുതിയ മാപ്പ്-കംപൈൽ പാരാമീറ്ററുകൾ, 120 000 യൂണിറ്റ് മാപ്പ് പരിധി.
- സ്വന്തം Python-ഉം സ്വയം അപ്ഡേറ്റും ഉള്ള പാക്കേജ് ചെയ്ത ലോഞ്ചർ; എഡിറ്ററിന്റെ പ്രാദേശികവൽക്കരണം.

## ലൈസൻസും കടപ്പാടും

C2UI-യുടെ സ്വന്തം കോഡ് **C2UI ലൈസൻസിന്** കീഴിലാണ്: വ്യക്തിഗതവും വാണിജ്യേതരവുമായ ഉപയോഗത്തിന് സ്വതന്ത്രം; വാണിജ്യ ഉപയോഗം രചയിതാവിന്റെ രേഖാമൂലമുള്ള സമ്മതത്തോടെ മാത്രം; പരിഷ്കരിച്ച പതിപ്പുകൾ യഥാർത്ഥ പ്രോജക്റ്റിനെയും രചയിതാവ് Arkomiko-യെയും പരാമർശിക്കണം. പ്ലഗിനുകളും ആഡ്ഓണുകളും **C2UI — Plugins & Addons (C2UI‑Pl&AD)** ലൈസൻസിന് കീഴിൽ.

Source Filmmaker, Team Fortress 2, Source എഞ്ചിൻ Valve-ന്റേതാണ്; പ്രോജക്റ്റ് അവയുടെ ഫോർമാറ്റുകൾ വായിക്കുന്നു, അവയുടെ ഫയലുകൾ ഉൾപ്പെടുത്തുന്നില്ല, Steam-ൽ നിന്നുള്ള നിങ്ങളുടെ സ്വന്തം SFM പകർപ്പുമായി മാത്രം പ്രവർത്തിക്കുന്നു.
