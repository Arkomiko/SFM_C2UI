## कल्पना

Source Filmmaker हे सशक्त साधन आहे, पण त्याचा इंटरफेस २०१२ मध्येच राहिला. C2UI त्याची जागा घेत नाही किंवा त्याला पुन्हा बनवत नाही: उद्दिष्ट फक्त SFM ला थोडे आधुनिक आणि सोयीचे करणे आहे.

एडिटर इन्स्टॉल केलेला SFM शोधतो, त्याला कंटेंट लायब्ररी म्हणून जोडतो — मॉडेल, मटेरियल, टेक्सचर, सेशन — आणि त्याच फाइल्सवर त्याच फॉरमॅटमध्ये काम करतो. SFM मध्ये बनवलेले सर्व C2UI मध्ये उघडते, आणि उलटही.

पहिले उद्दिष्ट हाडे आणि रिग्ससह SFM शी पूर्ण सुसंगतता. त्यानंतर — SFM मध्ये जे कमी होते ते.

```
  ┌───────────────┐                       ┌──────────────────────────────┐
  │   C2UI        │ ──── "SFM कुठे?" ────▶│  SourceFilmmaker/game/       │
  │               │                       │    usermod/gameinfo.txt      │
  │  स्वतःचा UI    │ ◀─────── माउंट ───────│    tf/  hl2/  tf_movies/ …   │
  │  स्वतःचा रेंडर │       फक्त वाचन        │    models/ materials/ dmx    │
  └───────────────┘                       └──────────────────────────────┘
```

- **पोर्टेबल.** अॅप्लिकेशन फोल्डरबाहेर काहीही लिहिले जात नाही: सेटिंग्ज `App/User` मध्ये, कॅश `App/Cache` मध्ये, तात्पुरते `App/Temporary` मध्ये. फोल्डर हटवा आणि खूण नाही.
- **SFM कधीही चालवत नाही.** चालवायला प्रोसेस नाही, ताब्यात घ्यायला खिडक्या नाहीत. इन्स्टॉलेशन कंटेंट पॅकसारखे वाचले जाते.
- **फॉरमॅट तपासलेले, गृहीत धरलेले नाही.** प्रत्येक रीडर खऱ्या इन्स्टॉलेशनशी तपासला; जिथे फॉरमॅट अनपेक्षित करतो, कोड सांगतो.
- **सेव्ह अचूक आहे.** न बदलता वाचलेले आणि लिहिलेले सेशन तीच फाइल आहे.
- **इंजिनला अवलंबित्व नाही.** `Core/` आणि संपूर्ण चाचणी संच शुद्ध Python वर चालतो; फक्त खिडकीला Qt आणि OpenGL लागते.

### हे कसे काम करते

«Source Filmmaker कुठे आहे?» पासून पडद्यावरील एका फ्रेमपर्यंतचा मार्ग पाच थरांतून जातो; प्रत्येक थर फक्त त्याच्या खालचा थर ओळखतो.

1. **ब्रिज** (`Core/dev-kit/bridge_sfm`) Steam द्वारे इन्स्टॉलेशन शोधतो, `gameinfo.txt` वाचतो आणि इंजिनच्या क्रमाने कंटेंटचे मार्ग परत देतो. `sfm.exe` कधीही सुरू होत नाही.
2. **व्हर्च्युअल फाइल सिस्टम आणि इंडेक्स** (`Core/Code/vfs.py`, `content_index.py`) हे मार्ग Source प्रमाणे थरांत लावतात: प्रथम सापडलेली फाइल जिंकते. इंडेक्स `App/Cache` मधील एक SQLite फाइल आहे, त्यामुळे 70 000 फाइलींची फेरी एकदाच होते.
3. **फॉरमॅट** (`Core/Code/formats`) तृतीय पक्ष लायब्ररीशिवाय Valve च्या फाइली वाचतात: `.mdl` `.vvd` `.vtx` म्हणजे मॉडेल, `.vmt` `.vtf` मटेरियल आणि टेक्स्चर, `.dmx` सेशन, `.bsp` नकाशा. प्रत्येक रीडर संपूर्ण इन्स्टॉलेशनवर तपासला आहे; सेशन बाइट-बाइट जसेच्या तसे परत लिहिले जाते.
4. **सेशन** हा DMX घटकांचा आलेख आहे. `animation.py` एका क्षणी चॅनेलचे मूल्य काढते, `operators.py` एक्स्प्रेशन आणि रिग कन्स्ट्रेंट चालवते, `flex.py` चेहरे हलवते, `pose.py` हाडांचे मॅट्रिक्स बनवते. प्रत्येक संपादन `editing.py` मधून रद्द करता येणारी आज्ञा म्हणून जाते.
5. **एडिटर** (`App/Code`) यातून एक दृश्य (`render/scene.py`) बनवतो आणि स्वतःच्या OpenGL 3.3 रेंडररने (`renderer.py`, `shaders.py`) काढतो: सेशनचे दिवे, लाइटमॅप आणि नकाशाची प्रकाशयोजना — SFM दाखवते तशीच. पॅनेल (`ui/`) म्हणजे टाइमलाइन, सेशन ट्री, इन्स्पेक्टर, ग्राफ एडिटर आणि UE5 शैलीतील डॉकिंग.

प्रोग्राम जे लिहितो ते त्याच्या फोल्डरमध्येच राहते: सेटिंग्ज `App/User` मध्ये, इंडेक्स आणि कॅशे `App/Cache` मध्ये, लॉग `App/Temporary` मध्ये. `Core/` काहीही लिहीत नाही आणि Qt वर अवलंबून नाही, त्यामुळे इंजिन आणि चाचण्या शुद्ध Python वर चालतात; Qt आणि OpenGL फक्त विंडोला लागतात. `Tools/` मधील साधने काटेकोरपणे `Core/API` वर बांधली आहेत — असेच सिद्ध होते की हा API तृतीय पक्ष प्लगइनसाठीही पुरेसा आहे.

### चालवणे

Windows, Python 3.13 आणि Source Filmmaker इन्स्टॉलेशन आवश्यक.

```bash
git clone https://github.com/Arkomiko/SFM_C2UI.git
cd SFM_C2UI
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r Tools/Launcher/requirements.txt
.venv/Scripts/python.exe Tools/Launcher/c2ui.py
```

पहिल्या सुरुवातीला Steam द्वारे SFM शोधते; न सापडल्यास विचारते. <kbd>Ctrl</kbd>+<kbd>O</kbd> सेशन उघडते, <kbd>Space</kbd> प्ले, <kbd>C</kbd> शॉट कॅमेरा, <kbd>T</kbd>/<kbd>R</kbd> मूव्ह/रोटेट, <kbd>M</kbd> मोशन एडिटर, <kbd>Ctrl</kbd>+<kbd>Z</kbd> अनडू, <kbd>Ctrl</kbd>+<kbd>S</kbd> सेव्ह. पॅनेल शीर्षकाने ओढले जातात. चाचण्यांना काही लागत नाही:

```bash
python Testing/run.py
```

### नियोजित

**पुढे**
- नकाशाचे रूप: स्कायबॉक्स, पाणी, prop_dynamic, दिव्यांचे गोबो टेक्स्चर, `$bumpmap` आणि `$envmap`, सेशनच्या दिव्यांच्या सावल्या.
- निर्यात: प्रतिमा अनुक्रम आणि व्हिडिओ.
- `.c2plg` प्लगइन आणि `Tools/Market Load` मधील मार्केटप्लेस क्लायंट; नंतर थीम आणि वर्कस्पेस.
- टाइमलाइनवर ध्वनी, पार्टिकल, रिंकल मॅप, मोशन एडिटरचे प्रीसेट आणि लेयर, ग्राफ एडिटरमधील टँजंट.

**नंतर**
- पूर्ण नकाशांवर कार्यक्षमता: स्टॅटिक प्रॉप्सचे इन्स्टन्सिंग, पोझ कॅशे.
- इंजिनची पुनर्रचना: सुधारित प्रकाश आणि सावल्यांसाठी नवे मॅप-कंपाइल पॅरामीटर, 120 000 युनिटची नकाशा मर्यादा.
- स्वतःच्या Python आणि स्व-अद्ययावतीकरणासह पॅकेज केलेला लाँचर; एडिटरचे स्थानिकीकरण.

## परवाना आणि आभार

C2UI चा स्वतःचा कोड **C2UI परवान्याखाली** आहे: वैयक्तिक व अव्यावसायिक वापरासाठी मुक्त; व्यावसायिक वापर फक्त लेखकाच्या लेखी संमतीने; सुधारित आवृत्त्यांमध्ये मूळ प्रकल्प व त्याचा लेखक Arkomiko यांचा उल्लेख आवश्यक. प्लगइन व अ‍ॅडऑन **C2UI — Plugins & Addons (C2UI‑Pl&AD)** परवान्याखाली.

Source Filmmaker, Team Fortress 2 व Source इंजिन Valve चे आहेत; प्रकल्प त्यांचे फॉरमॅट वाचतो, त्यांची फाइल समाविष्ट करत नाही, आणि फक्त Steam वरील तुमच्या SFM प्रतीसह काम करतो.
