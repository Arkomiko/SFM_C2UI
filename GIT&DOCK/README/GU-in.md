## વિચાર

Source Filmmaker એક મજબૂત સાધન છે જેનું ઇન્ટરફેસ 2012 માં જ રહી ગયું. C2UI તેને બદલતું કે ફરી બનાવતું નથી: લક્ષ્ય ફક્ત SFM ને થોડું આધુનિક અને સુવિધાજનક બનાવવાનું છે.

એડિટર ઇન્સ્ટોલ કરેલું SFM શોધે છે, તેને કન્ટેન્ટ લાઇબ્રેરી તરીકે જોડે છે — મોડેલ, મટીરિયલ, ટેક્સચર, સેશન — અને એ જ ફાઇલો સાથે એ જ ફોર્મેટમાં કામ કરે છે. SFM માં બનાવેલું બધું C2UI માં ખુલે છે, અને ઊલટું પણ.

પહેલું લક્ષ્ય હાડકાં અને રિગ સહિત SFM સાથે સંપૂર્ણ સુસંગતતા. પછી — જે SFM માં ખૂટતું હતું.

```
  ┌────────────────┐                       ┌──────────────────────────────┐
  │   C2UI         │ ──── "SFM ક્યાં?" ────▶│  SourceFilmmaker/game/       │
  │                │                       │    usermod/gameinfo.txt      │
  │  પોતાનું UI    │ ◀─────── માઉન્ટ ───────│    tf/  hl2/  tf_movies/ …   │
  │  પોતાનું રેન્ડર │       ફક્ત વાંચન       │    models/ materials/ dmx    │
  └────────────────┘                       └──────────────────────────────┘
```

- **પોર્ટેબલ.** એપ્લિકેશન ફોલ્ડર બહાર કંઈ લખાતું નથી: સેટિંગ્સ `App/User` માં, કેશ `App/Cache` માં, કામચલાઉ `App/Temporary` માં. ફોલ્ડર કાઢી નાખો અને કોઈ નિશાન નહીં.
- **SFM ક્યારેય ચલાવતું નથી.** ચલાવવા માટે કોઈ પ્રોસેસ નહીં, કબજે કરવા કોઈ વિન્ડો નહીં. ઇન્સ્ટોલેશન કન્ટેન્ટ પેક જેમ વંચાય છે.
- **ફોર્મેટ ચકાસેલા, માનેલા નહીં.** દરેક રીડર વાસ્તવિક ઇન્સ્ટોલેશન સામે તપાસ્યો; જ્યાં ફોર્મેટ કંઈ અનપેક્ષિત કરે, કોડ કહે છે.
- **સેવ ચોક્કસ છે.** બદલ્યા વિના વાંચેલી અને લખેલી સેશન એ જ ફાઇલ છે.
- **એન્જિનને કોઈ નિર્ભરતા નથી.** `Core/` અને સંપૂર્ણ ટેસ્ટ સ્યુટ શુદ્ધ Python પર ચાલે છે; ફક્ત વિન્ડોને Qt અને OpenGL જોઈએ.

### આ કેવી રીતે કામ કરે છે

«Source Filmmaker ક્યાં છે?» થી સ્ક્રીન પરની એક ફ્રેમ સુધીનો માર્ગ પાંચ સ્તરોમાંથી પસાર થાય છે; દરેક સ્તર ફક્ત પોતાની નીચેના સ્તરને જ જાણે છે.

1. **બ્રિજ** (`Core/dev-kit/bridge_sfm`) Steam દ્વારા ઇન્સ્ટોલેશન શોધે છે, `gameinfo.txt` વાંચે છે અને એન્જિનના ક્રમમાં કન્ટેન્ટ પાથ પરત આપે છે. `sfm.exe` ક્યારેય ચલાવવામાં આવતું નથી.
2. **વર્ચ્યુઅલ ફાઇલ સિસ્ટમ અને ઇન્ડેક્સ** (`Core/Code/vfs.py`, `content_index.py`) આ પાથને Source ની જેમ સ્તરોમાં ગોઠવે છે: પહેલી મળેલી ફાઇલ જીતે છે. ઇન્ડેક્સ `App/Cache` માં એક SQLite ફાઇલ છે, તેથી 70 000 ફાઇલોની ફેરી એક જ વાર થાય છે.
3. **ફોર્મેટ** (`Core/Code/formats`) તૃતીય પક્ષ લાઇબ્રેરી વિના Valve ની ફાઇલો વાંચે છે: `.mdl` `.vvd` `.vtx` મોડેલ છે, `.vmt` `.vtf` મટીરિયલ અને ટેક્સચર, `.dmx` સેશન, `.bsp` નકશો. દરેક રીડર આખા ઇન્સ્ટોલેશન પર ચકાસાયેલ છે; સેશન બાઇટ-બાઇટ એવું જ પાછું લખાય છે.
4. **સેશન** DMX તત્વોનો ગ્રાફ છે. `animation.py` એક ક્ષણે ચેનલોની ગણતરી કરે છે, `operators.py` એક્સપ્રેશન અને રિગ કન્સ્ટ્રેન્ટ ચલાવે છે, `flex.py` ચહેરા હલાવે છે, `pose.py` હાડકાંના મેટ્રિક્સ બનાવે છે. દરેક ફેરફાર `editing.py` માંથી પાછો વાળી શકાય તેવા આદેશ તરીકે પસાર થાય છે.
5. **એડિટર** (`App/Code`) આમાંથી એક દૃશ્ય (`render/scene.py`) બનાવે છે અને તેને પોતાના OpenGL 3.3 રેન્ડરર (`renderer.py`, `shaders.py`) વડે દોરે છે: સેશનની લાઇટો, લાઇટમેપ અને નકશાની રોશની — SFM બતાવે છે તેવી જ. પેનલો (`ui/`) એટલે ટાઇમલાઇન, સેશન ટ્રી, ઇન્સ્પેક્ટર, ગ્રાફ એડિટર અને UE5 શૈલીનું ડોકિંગ.

પ્રોગ્રામ જે લખે છે તે તેના ફોલ્ડરમાં જ રહે છે: સેટિંગ્સ `App/User` માં, ઇન્ડેક્સ અને કેશ `App/Cache` માં, લોગ `App/Temporary` માં. `Core/` કંઈ લખતું નથી અને Qt પર આધાર રાખતું નથી, તેથી એન્જિન અને ટેસ્ટ શુદ્ધ Python પર ચાલે છે; Qt અને OpenGL ફક્ત વિન્ડોને જોઈએ. `Tools/` ની ઉપયોગિતાઓ કડક રીતે `Core/API` પર બનેલી છે — આ રીતે સાબિત થાય છે કે API તૃતીય પક્ષ પ્લગઇન માટે પણ પૂરતું છે.

### ચલાવવું

Windows, Python 3.13 અને Source Filmmaker ઇન્સ્ટોલેશન જરૂરી.

```bash
git clone https://github.com/Arkomiko/SFM_C2UI.git
cd SFM_C2UI
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r Tools/Launcher/requirements.txt
.venv/Scripts/python.exe Tools/Launcher/c2ui.py
```

પહેલી વાર Steam દ્વારા SFM શોધે છે; ન મળે તો પૂછે છે. <kbd>Ctrl</kbd>+<kbd>O</kbd> સેશન ખોલે છે, <kbd>Space</kbd> પ્લે, <kbd>C</kbd> શોટ કેમેરા, <kbd>T</kbd>/<kbd>R</kbd> મૂવ/રોટેટ, <kbd>M</kbd> મોશન એડિટર, <kbd>Ctrl</kbd>+<kbd>Z</kbd> અનડુ, <kbd>Ctrl</kbd>+<kbd>S</kbd> સેવ. પેનલ શીર્ષકથી ખેંચાય છે. પરીક્ષણોને કંઈ જોઈતું નથી:

```bash
python Testing/run.py
```

### યોજનામાં

**આગળ**
- નકશાનો દેખાવ: પાણી, prop_dynamic, લાઇટના ગોબો ટેક્સચર, `$bumpmap` અને `$envmap`, સેશન લાઇટોના પડછાયા.
- નિકાસ કરેલી ફિલ્મોમાં અવાજ.
- `.c2plg` પ્લગઇન અને `Tools/Market Load` માં માર્કેટપ્લેસ ક્લાયન્ટ; પછી થીમ અને વર્કસ્પેસ.
- ટાઇમલાઇન પર અવાજ, પાર્ટિકલ, રિંકલ મેપ, મોશન એડિટરના પ્રીસેટ અને લેયર, ગ્રાફ એડિટરમાં ટેન્જન્ટ.

**પછી**
- પૂર્ણ નકશા પર કામગીરી: સ્ટેટિક પ્રોપ્સનું ઇન્સ્ટન્સિંગ, પોઝ કેશ.
- એન્જિનનું પુનર્નિર્માણ: સુધારેલી રોશની અને પડછાયા માટે નવા મેપ-કમ્પાઇલ પેરામીટર, 120 000 યુનિટની નકશા મર્યાદા.
- પોતાના Python અને સ્વ-અપડેટ સાથેનું પેકેજ્ડ લોન્ચર; એડિટરનું સ્થાનિકીકરણ.

## લાઇસન્સ અને આભાર

C2UI નો પોતાનો કોડ **C2UI લાઇસન્સ** હેઠળ છે: વ્યક્તિગત અને બિન-વ્યાવસાયિક ઉપયોગ માટે મુક્ત; વ્યાવસાયિક ઉપયોગ ફક્ત લેખકની લેખિત સંમતિથી; સુધારેલી આવૃત્તિઓમાં મૂળ પ્રોજેક્ટ અને તેના લેખક Arkomiko નો ઉલ્લેખ જરૂરી. પ્લગઇન અને એડઓન **C2UI — Plugins & Addons (C2UI‑Pl&AD)** લાઇસન્સ હેઠળ.

Source Filmmaker, Team Fortress 2 અને Source એન્જિન Valve ના છે; પ્રોજેક્ટ તેમના ફોર્મેટ વાંચે છે, તેમની કોઈ ફાઇલ સમાવતો નથી, અને ફક્ત Steam પરથી તમારી પોતાની SFM નકલ સાથે કામ કરે છે.
