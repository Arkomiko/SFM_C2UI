## विचार

Source Filmmaker एक बलियो उपकरण हो जसको इन्टरफेस २०१२ मै रह्यो। C2UI ले यसलाई प्रतिस्थापन वा पुनर्निर्माण गर्दैन: लक्ष्य केवल SFM लाई अलि आधुनिक र सहज बनाउनु हो।

सम्पादकले स्थापित SFM फेला पार्छ, यसलाई सामग्री पुस्तकालयका रूपमा जोड्छ — मोडेल, सामग्री, टेक्सचर, सेसन — र उही फाइलहरूसँग उही ढाँचामा काम गर्छ। SFM मा बनेको सबै C2UI मा खुल्छ, र उल्टो पनि।

पहिलो लक्ष्य हड्डी र रिगसहित SFM सँग पूर्ण अनुकूलता हो। त्यसपछि — SFM मा जे कमी थियो।

```
  ┌──────────────┐                       ┌──────────────────────────────┐
  │   C2UI       │ ──── "SFM कहाँ?" ────▶│  SourceFilmmaker/game/       │
  │              │                       │    usermod/gameinfo.txt      │
  │  आफ्नै UI     │ ◀─────── माउन्ट ───────│    tf/  hl2/  tf_movies/ …   │
  │  आफ्नै रेन्डर  │       पढ्ने मात्र       │    models/ materials/ dmx    │
  └──────────────┘                       └──────────────────────────────┘
```

- **पोर्टेबल।** एप्लिकेसन फोल्डरबाहिर केही लेखिँदैन: सेटिङ `App/User` मा, क्यास `App/Cache` मा, अस्थायी `App/Temporary` मा। फोल्डर मेट्नुहोस्, कुनै छाप छैन।
- **SFM कहिल्यै चलाउँदैन।** चलाउने प्रोसेस छैन, कब्जा गर्ने विन्डो छैन। स्थापना सामग्री प्याकजस्तै पढिन्छ।
- **ढाँचा प्रमाणित, अनुमानित होइन।** हरेक रिडर वास्तविक स्थापनासँग जाँचिएको; ढाँचाले अनपेक्षित गर्ने ठाउँमा कोड बताउँछ।
- **सेभ सटीक छ।** नबदलेर पढिएको र लेखिएको सेसन उही फाइल हो।
- **इन्जिनको कुनै निर्भरता छैन।** `Core/` र सम्पूर्ण परीक्षण सुइट शुद्ध Python मा चल्छ; विन्डोलाई मात्र Qt र OpenGL चाहिन्छ।

### यो कसरी काम गर्छ

«Source Filmmaker कहाँ छ?» देखि स्क्रिनमा एउटा फ्रेमसम्मको बाटो पाँच तहबाट जान्छ; हरेक तहले आफ्नो तलको तह मात्र चिन्छ।

1. **ब्रिज** (`Core/dev-kit/bridge_sfm`) ले Steam मार्फत इन्स्टलेसन भेट्टाउँछ, `gameinfo.txt` पढ्छ र इन्जिनको क्रममा सामग्रीका बाटाहरू फर्काउँछ। `sfm.exe` कहिल्यै चलाइँदैन।
2. **भर्चुअल फाइल प्रणाली र सूचकांक** (`Core/Code/vfs.py`, `content_index.py`) ले ती बाटाहरूलाई Source जस्तै तहमा राख्छन्: पहिले भेटिएको फाइलले जित्छ। सूचकांक `App/Cache` मा एउटा SQLite फाइल हो, त्यसैले 70 000 फाइलको फन्को एकपटक मात्र लाग्छ।
3. **ढाँचाहरू** (`Core/Code/formats`) ले तेस्रो पक्षका लाइब्रेरीबिना Valve का फाइलहरू पढ्छन्: `.mdl` `.vvd` `.vtx` मोडेल, `.vmt` `.vtf` सामग्री र टेक्स्चर, `.dmx` सत्र, `.bsp` नक्सा। हरेक रिडर पूरै इन्स्टलेसनमा जाँचिएको छ; सत्र बाइट-बाइट उस्तै फिर्ता लेखिन्छ।
4. **सत्र** DMX तत्वहरूको ग्राफ हो। `animation.py` ले कुनै क्षणमा च्यानलहरू गणना गर्छ, `operators.py` ले अभिव्यक्ति र रिग कन्स्ट्रेन्ट चलाउँछ, `flex.py` ले अनुहार चलाउँछ, `pose.py` ले हड्डी म्याट्रिक्स बनाउँछ। हरेक सम्पादन `editing.py` बाट पूर्ववत गर्न मिल्ने आदेशका रूपमा जान्छ।
5. **सम्पादक** (`App/Code`) ले यसबाट एउटा दृश्य (`render/scene.py`) बनाउँछ र आफ्नै OpenGL 3.3 रेन्डरर (`renderer.py`, `shaders.py`) ले कोर्छ: सत्रका बत्ती, लाइटम्याप र नक्साको प्रकाश — तस्बिर अझै SFM बाट धेरै टाढा छ, काम जारी छ। प्यानलहरू (`ui/`) टाइमलाइन, सत्र ट्री, इन्स्पेक्टर, ग्राफ सम्पादक र UE5 शैलीको डकिङ हुन्।

कार्यक्रमले लेख्ने सबै कुरा उसकै फोल्डरमा रहन्छ: सेटिङ `App/User` मा, सूचकांक र क्यास `App/Cache` मा, लग `App/Temporary` मा। `Core/` ले केही लेख्दैन र Qt मा निर्भर छैन, त्यसैले इन्जिन र परीक्षणहरू शुद्ध Python मा चल्छन्; Qt र OpenGL झ्याललाई मात्र चाहिन्छ। `Tools/` का उपकरणहरू कडाइका साथ `Core/API` माथि बनेका छन् — यसरी नै प्रमाणित हुन्छ कि यो API तेस्रो पक्षका प्लगइनका लागि पनि पर्याप्त छ।

### चलाउने

Windows, Python 3.13 र Source Filmmaker स्थापना आवश्यक।

```bash
git clone https://github.com/Arkomiko/SFM_C2UI.git
cd SFM_C2UI
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r Launcher/requirements.txt
.venv/Scripts/python.exe Launcher/launcher.py
```

यसले लन्चर खोल्छ: तीन बटन भएको सानो विन्डो। यसको रूप अस्थायी हो — App बनेपछि पुनः लेखिनेछ; यसको विन्डो अहिले रुसी भाषामा मात्र छ।

<p align="center"><a href="../LAUNCHER/NE-np.md"><img alt="लन्चरबारे" src="https://img.shields.io/badge/%E0%A4%B2%E0%A4%A8%E0%A5%8D%E0%A4%9A%E0%A4%B0%E0%A4%AC%E0%A4%BE%E0%A4%B0%E0%A5%87-66c0f4?style=for-the-badge"></a></p>

पहिलो पटक Steam मार्फत SFM खोज्छ; नपाए सोध्छ। <kbd>Ctrl</kbd>+<kbd>O</kbd> सेसन खोल्छ, <kbd>Space</kbd> प्ले, <kbd>C</kbd> शट क्यामेरा, <kbd>T</kbd>/<kbd>R</kbd> मुभ/रोटेट, <kbd>M</kbd> मोशन सम्पादक, <kbd>Ctrl</kbd>+<kbd>Z</kbd> अन्डु, <kbd>Ctrl</kbd>+<kbd>S</kbd> सेभ। प्यानल शीर्षकबाट तानिन्छन्। परीक्षणलाई केही चाहिँदैन:

```bash
python Testing/run.py
```

### योजनामा

**अर्को**
- नक्साको रूप: पानी, prop_dynamic, बत्तीका गोबो टेक्स्चर, `$bumpmap` र `$envmap`, सत्रका बत्तीबाट छायाँ।
- निर्यात गरिएका फिल्ममा ध्वनि।
- `.c2plg` प्लगइन र `Tools/Market Load` मा मार्केटप्लेस क्लाइन्ट; त्यसपछि थिम र कार्यक्षेत्र।
- टाइमलाइनमा ध्वनि, कण, रिङ्कल म्याप, मोसन सम्पादकका प्रिसेट र तह, ग्राफ सम्पादकमा ट्यान्जेन्ट।

**पछि**
- पूर्ण नक्सामा प्रदर्शन: स्थिर प्रप इन्स्टान्सिङ, पोज क्यास।
- इन्जिनको पुनर्निर्माण: राम्रो प्रकाश र छायाँका लागि नयाँ नक्सा-कम्पाइल प्यारामिटर, 120 000 एकाइको नक्सा सीमा।
- आफ्नै Python र स्व-अद्यावधिकसहितको प्याकेज गरिएको लन्चर; सम्पादकको स्थानीयकरण।

## इजाजतपत्र र आभार

C2UI को आफ्नै कोड **C2UI इजाजतपत्र** अन्तर्गत छ: व्यक्तिगत र गैर-व्यावसायिक प्रयोगका लागि स्वतन्त्र; व्यावसायिक प्रयोग लेखकको लिखित सहमतिमा मात्र; परिमार्जित संस्करणहरूले मूल परियोजना र यसका लेखक Arkomiko उल्लेख गर्नुपर्छ। प्लगइन र एडअन **C2UI — Plugins & Addons (C2UI‑Pl&AD)** इजाजतपत्र अन्तर्गत।

Source Filmmaker, Team Fortress 2 र Source इन्जिन Valve का हुन्; परियोजनाले तिनका ढाँचा पढ्छ, तिनको कुनै फाइल समावेश गर्दैन, र Steam बाट तपाईंको आफ्नै SFM प्रतिसँग मात्र काम गर्छ।
